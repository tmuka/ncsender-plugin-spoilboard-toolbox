Z zero on the spoilboard. Probe a block on the spoilboard once and the wizard remembers the spoilboard height for a zero-length tool. After that, one macro puts work Z0 on the spoilboard with any tool whose length offset is measured, with no probing.

1Check the controller

Asks the controller for its state ($G, $#) and tries one harmless expression. Nothing moves.

    2Settings

    The height is kept in a spare work offset's Z, which the controller saves through power cycles. Pick one you don't use. The macros switch to mm (G21) while they work, because grblHAL reports stored offsets and tool lengths in mm whatever the units mode.

    1. Set the probe block on the spoilboard and load a tool whose length offset is measured and active.
      2. 
        
    2. Jog the bit just above the block, then run the record macro from the Macros tab. It probes down, stores the height, and backs off.
      3. 
        
    3. Without changing tools, run the set macro.
      4. 
        
    4. Jog down onto the block with a paper feeler. Work Z should read about the block thickness. If it doesn't, don't use the macros until it does.
      5. 
        
    5. Then change to another measured tool and run only the set macro.
