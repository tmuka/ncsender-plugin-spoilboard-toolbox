Z zero on the spoilboard. Probe a block on the spoilboard once and the wizard remembers the spoilboard height for a zero-length tool. After that, with any tool whose length offset is measured and no probing, one macro puts work Z0 on the spoilboard, another on top of stock of a known thickness, and a third puts your own Z0 back.

1Check the controller

Asks the controller for its state ($G, $#) and tries one harmless expression. Nothing moves.

    2Settings

    The height and the saved Z0 are kept in two spare work offsets' Z, which the controller keeps through power cycles; pick ones you don't use. Stock Thickness adds a macro that puts Z0 that far above the spoilboard (0 leaves it out). The macros switch to mm (G21) while they work, because grblHAL reports stored offsets and tool lengths in mm whatever the units mode.

    3Macros

    The spoilboard and stock-top macros save the current Z0 first, unless it's already one of theirs, so back to saved returns to your probed Z0 however many times you switch.

    4Try it once

    1. Set the probe block on the spoilboard and load a tool whose length offset is measured and active.
    2. Jog the bit just above the block, then run the record macro from the Macros tab. It probes down, stores the height, and backs off.
    3. Without changing tools, run the set macro.
    4. Jog down onto the block with a paper feeler. Work Z should read about the block thickness. If it doesn't, don't use the macros until it does.
    5. Run back to saved: work Z0 returns to where it was before step 3.
    6. Then change to another measured tool and run only the spoilboard (or stock-top) macro.

    Re-run the record macro if the spoilboard is resurfaced or your reference tool changes.
